## One workspace, several ways to create

| Feature | What you can do |
|---|---|
| 🗂️ Manual PVF editing | Browse files, search paths and text, edit scripts, and manage imports and exports. |
| ✦ AI assistance | Explain files and selections, investigate references, and generate changes to review using your configured AI connection. |
| 🔎 Review before applying | Inspect differences and affected files, choose changes, then confirm application and check the save result. |
| 🎞️ Resource and specialized tools | Explore supported NPK/IMG/animation resources and use supported skill, dungeon and MOD workflows with your own files. |
| 🔌 MCP and Agent workflows | Connect external AI clients through MCP, manage tool permissions, and inspect task results and deployment plans. |
| ⟳ Updates and guidance | Check for official updates inside the app; after confirmation, download, verify and restart. Find steps in the built-in operation guide. |

**The interface is currently primarily Chinese.** The translations below describe the release; they do not indicate translated application interfaces. Feature availability depends on the PVF format, matching client profile, configured tools and resources. A successful edit or build does not establish an in-game result.

## Download & start

1. Download **OI DOF全自动编辑器-4.1.1.zip** from the release assets.
2. Extract it into a writable folder and run **OI DOF全自动编辑器-4.1.1.exe**. Windows x64 and the Microsoft Edge WebView2 Runtime are required.
3. Supply your own PVF. Open **操作指引** for the first steps. AI is optional; manual editing does not require a model connection.
4. For AI assistance, configure a model API or an installed, signed-in local AI client. For updates, use the app's update entry; future official updates follow the official signed channel, not GitHub release polling.
